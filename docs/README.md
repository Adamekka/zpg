# Project documentation

These files contain the project's agreed requirements.

- [Vertex data](vertex-data.md): runtime vertex layouts and shader input locations.
- [Transformations](transformations.md): composition, matrix order, and animation.
- [Scenes](scenes.md): scene creation, ownership, updates, and rendering.
- [Camera](camera.md): view and projection matrices and shader inputs.
- [Forest](forest.md): flying controls, ground, trees, and clocks.
- [Clock](clock.md): local time, drawing, and part colors.
- [Model import](model-import.md): static glTF models, materials, textures, and asset credit.
- [Lighting demonstrations](lighting.md): exercise 7, normal transforms, specular clipping, resizing, and the night forest.
